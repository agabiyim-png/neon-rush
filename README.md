# NEON RUSH — Endless Escape

An original offline, ad-free, portrait Android arcade game. Built in Java using a custom Android Canvas and no external runtime game engine.

## Play
Slide a finger horizontally, dodge the red obstacles, grab gold energy cores and cyan shields, and build combos. Every completed mission unlocks a cosmetic ship color. Tap to retry after a crash. Pause from the top-right button.

## Build APK
Open **Actions → Neon Rush - Android APK → latest successful run → Artifacts → Neon-Rush-Android-APK**. Unzip and install `app-debug.apk` on Android. GitHub login may be required for artifacts. Debug builds are for testing only, not Play Store releases.

## Privacy
No analytics, advertising, accounts, network access, or sensitive permissions. Local high score and unlocked color are stored only in Android SharedPreferences.
